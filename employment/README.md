## Method and limits
Pilot list built from retrievable statewide PA 211 entries, the West
Central Job Partnership's own site (wcjp.org), the pa.gov OVR office
directory (fetched 2026-11-22), LCCAP, LCCTC, BC3, the Lawrence
County Learning Center, the Lawrence-Mercer Manufacturers Coalition,
the Lawrence County District Attorney's Office, and county/chamber
lists; each item checked against the organisation's own website/page.
Own site beats directory; directory beats a third-party aggregator.
County for every address was verified by exact geocoding, never by
ZIP or town name alone. No organisation was contacted. No page-text
fetch in this run hit a rate limit. The OVR relocation, BC3 Lawrence
Crossing closure and Learning Center move rest on own-site pages as
returned in search results plus the fetched pa.gov OVR directory, and
are flagged for live confirmation before any send.

PA 211's search pages are JavaScript-driven and text fetch cannot pull
a complete county-filtered list, so this is a partial pilot anchored on
retrievable PA 211 items plus secondary lists plus organisations' own
sites — NOT a complete county directory. A live-browser PA 211
Lawrence County check is outstanding before any send.
