## Method and limits

Pilot list built from retrievable PA 211 items plus secondary lists (Inglis Lawrence County Quick Start guide; PA DHS county guides and state programme pages; MIU IV directory; ODP SCO Directory, July 24, 2026). Every item checked against the organisation's own website/page or a state programme page. Own site beats directory; directory beats a third-party aggregator. Every address verified by exact geocoding, never by ZIP or town name alone (New Castle addresses = Lawrence County; Grove City = Mercer County; Erie = Erie County; Pittsburgh = Allegheny County; Hermitage = Mercer County; Harrisburg = Dauphin County). ZIP code does not settle county: PA 211's "16015" for the Lawrence AAA is wrong (correct: 16105).

Five statewide items (DRP, ODHH, PATF, PA Client Assistance Program, ASERT) were carried from the Snyder County disability audit (2026-11-15) and not re-fetched in this run; they are marked CLARIFIED and listed for re-confirmation in the pre-send re-check list. No page-text fetch rate limit was hit in this check. A live-browser re-check is outstanding — see the pre-send re-check list in the audit report.

This audit checks contact information only. It does not assess service quality, eligibility outcomes, or benefits/legal advice. No organisation is called closed or defunct. UNVERIFIED means the own-site evidence was not found in this check, not that a service has ended.
