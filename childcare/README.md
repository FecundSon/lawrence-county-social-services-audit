## ELRC region for Lawrence County

**Lawrence County is in ELRC Region 3** — Early Learning Resource Center Region 3, serving Armstrong, Beaver, Butler, Indiana and Lawrence Counties. Main office: 139 Rieger Rd, Butler, PA 16001-0257, (724) 285-9431, toll-free 1-888-864-1654, elrc3.com. Subsidy route: Child Care Works, administered by ELRC Region 3; statewide helpline 1-877-4-PA-KIDS.
